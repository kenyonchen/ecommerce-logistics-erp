# 08 · 用户故事与验收标准

> 用「史诗 → 用户故事 → 验收标准」组织需求，供开发估算与测试验收使用。
> **覆盖**列说明当前系统状态：✅ 已可验收 ｜ 🟡 部分满足 ｜ ⚪ 尚未实现 ｜ ❌ 调用即失败。
> 优先级采用 **MoSCoW**：M=必须有，S=应该有，C=可以有，W=暂不做。
